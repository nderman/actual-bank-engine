Actual Bank Engine

Extensible banking → Actual Budget sync, running as a pure Vercel serverless API.

This host exposes machine endpoints only — there is no web UI:

  • GET /api/cron/sync — scheduled polling sweep (requires a bearer secret)
  • POST /api/webhooks/<bank> — real-time ingestion for push-capable banks

Source & docs: github.com/nderman/actual-bank-engine
